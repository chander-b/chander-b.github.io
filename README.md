# Chander Bhushan — Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a GitHub repository named exactly `YOUR_GITHUB_USERNAME.github.io`.
2. Upload the contents of this folder (not the ZIP file) to the repository root.
3. Commit to the `main` branch.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Your site will be available at `https://YOUR_GITHUB_USERNAME.github.io/` after deployment.
